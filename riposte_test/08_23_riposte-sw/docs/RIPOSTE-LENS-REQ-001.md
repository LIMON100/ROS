## 1. 목적 및 범위

이중 EO(광각/협각) 채널의 렌즈 요구사항을 정의한다. 두 채널 모두 **M12(S-mount)로
통일**한다 — 무게 총 ~25–35 g(C-mount 협각 대비 ~50 g 절감), 홀더 공용화, 소형
수직 적층으로 기선 ~30–40 mm 단축이 근거다. 대가는 협각 채널의 MTF 검증 부담이며,
이를 §5의 조달·수락 조건으로 관리한다.

**렌즈 초점거리는 R-3(300 m 탐지) 성립의 민감 변수다** (DUALEO-REQ §3.3-4).
본 문서의 수치는 그 분석에서 도출되었고, 여기서 바꾸면 상위 문서의 거리 대역
설계(R-5 역할 분담)가 함께 움직인다.

## 2. 전제

### 2.1 센서 (양 채널 공통)

| 항목 | 값 |
|---|---|
| 센서 | Sony IMX568, 1/1.8" 글로벌 셔터 |
| 해상도 / 픽셀 | 2472 × 2064 (5.1 MP) / 2.74 µm |
| 유효 면적 / 대각 | 6.77 × 5.66 mm / **8.8 mm** |
| 나이퀴스트 | 182 lp/mm (판정 주파수는 그 절반 91 lp/mm 사용) |
| 캡처 | 60 fps 고정(S-11), 노출 상한 ~15 ms, 외부 트리거 동기 |

### 2.2 배치 (렌즈 사양의 기구 전제)

- **네스티드 동축 배치**: 협각 HFOV 15°가 광각 HFOV 59°의 중심에 오도록 광축 평행
  정렬. 독립/부분중첩 배치는 획득 깔때기(광각 획득 → 협각 정밀 추적) 구조와
  핸드오프를 깨므로 기각.
- **수직 적층, 기선 ≤60 mm**(M12 기준 ~30–40 mm 목표): 시차 오프셋을 고도각
  방향으로 격리해 PN/yaw 센터링(R-9)의 임계 축인 방위각을 두 채널에서 일치시킨다.
  기선 50 mm의 시차는 300 m에서 0.17 mrad, 30 m에서 1.7 mrad — 해당 거리의 대상
  bbox 대비 무시 가능하며 상수 보정으로 흡수.
- 공통 강성 플레이트 장착, 기계 정렬 ±0.5°, 잔차는 SW 각오프셋 보정(config).
- 보정 절차: ≥50 m 원거리 대상(또는 콜리메이터) 공장 보정 → 비행 중 핸드오프
  잔차로 검증. (상세 절차는 DUALEO-REQ DEFERRED 항목에서 구체화)

## 4. 채널별 요구사항

### 4.1 광각 채널 (L-W) — f6 mm

| ID | 항목 | 요구 |
|---|---|---|
| L-W1 | 초점거리 | **6.0 mm ±5%** → HFOV ~59°, VFOV ~50° |
| L-W2 | 조리개 | **F2.0** (허용 상한 F2.8) |
| L-W3 | 왜곡 | TV distortion ≤ 2% (배럴형) — 잔여는 SW 보정하되, 큰 왜곡은 타일 경계 좌표 사상 오차의 원인 |
| L-W4 | MTF | 중심 ≥50%, 0.7 필드 ≥30% @ 91 lp/mm |
| L-W5 | 크기/무게 | Ø14 × ~20 mm, ~8–12 g |
| L-W6 | 초점 세팅 | 과초점(F2.0 기준 H≈3.3 m) → 1.7 m~∞ 선명 (근거리 종말 단계 커버) |

광각 f6/1/1.8"/5MP M12는 시장 표준품 — 조달 리스크 낮음.

### 4.2 협각 채널 (L-N) — f25 mm ⚠️리스크 집중 지점

| ID | 항목 | 요구 |
|---|---|---|
| L-N1 | 초점거리 | **25 mm ±5%** → HFOV ~15.4°. **f16은 300 m에서 ~5 px로 R-3 미달 — 25 mm가 하한.** f35(HFOV 11°, 11.6 px)는 큐 정확도 요구가 ±7°→±5°로 조여져 GCS 큐 실측 전 채택 보류(DUALEO-REQ §3.3-4) |
| L-N2 | 조리개 | **F2.4** (허용 상한 F2.8) — 60 fps 노출 상한 15 ms에서 주간 여유 |
| L-N3 | 왜곡 | ≤ 0.5% (장초점 자연 충족) |
| L-N4 | MTF | **중심 ≥40% @ 91 lp/mm — 본 문서의 핵심 항목.** 대상은 큐/센터링으로 중심 근방에 오므로 중심 MTF가 곧 300 m 탐지 하한. 0.7 필드는 ≥25%로 완화 가능 |
| L-N5 | 크기/무게 | Ø14–16 × 35–45 mm, 15–25 g |
| L-N6 | 초점 세팅 | 과초점 H≈47 m(F2.4, c=5.5 µm) → **24 m~∞ 선명** — 협각 운용 대역(30–300 m)과 일치. 근거리(<30 m)는 광각 담당 |
| L-N7 | 기구 보강 | 배럴이 길어 캔틸레버 진동 취약 — **배럴 전방 지지 브래킷** 필수, 락넛 + 나사고정제 |

## 5. 조달·수락 조건 (발주서 포함 항목)

| ID | 조건 |
|---|---|
| V-1 | **샘플 실측 MTF 비교**: 협각 25 mm × 1/1.8" × 5 MP M12는 후보군이 좁다. M12 전문 벤더(Evetar, Lensation, Commonlands, Kowa M12 라인 등)에서 L-C2 만족 후보를 선별, **발주 전 샘플 2–3종의 실측 MTF 비교를 발주 조건으로** 한다. 2.74 µm 픽셀에서 M12 장초점의 카탈로그–실물 편차가 큰 것이 알려진 리스크 |
| V-2 | **시스템 지표 수락 시험**: 렌즈 단품 MTF 외에, 실 센서 결합 상태에서 "0.35 m 대상판 @300 m(또는 스케일 등가 콜리메이터)에서 bbox ≥8 px 검출" — DUALEO-REQ §3.1의 검출 하한 가정을 수락 기준으로 그대로 사용 |
| V-3 | **폴백 경로**: 샘플 전종 MTF 미달 시 **협각만 C-mount 복귀**(재설계 범위: 홀더·브래킷 국한). 네스티드 배치·기선·광각 M12는 불변 |
| V-4 | **온도 시험**: −20/+25/+60 °C에서 초점 이동 측정 — 협각은 원경 측 DOF가 넓어 여유 예상되나 실측 확인 |

## 6. ASSUMPTION / DEFERRED

| 태그 | 항목 |
|---|---|
| ASSUMPTION | 검출 하한 8 px @640 모델 입력 (DUALEO-REQ §3.1 — 모델 검증으로 갱신 시 본 문서 수치 연동 재검토) |
| ASSUMPTION | IMX568 CRA 값은 데이터시트 확정치로 L-C7에 반영 (현재 대략치) |
| DEFERRED | 협각 f25 vs f35 최종 결정 — GCS 큐 방위 정확도 실측(±7° 이내 여부) 후 |
| DEFERRED | 홀더 규격(백포커스·나사 길이)·브래킷 도면 — 렌즈 기종 확정 후 기구 설계 |
| DEFERRED | 두 채널 외부 파라미터 보정 절차 상세 (DUALEO-REQ DEFERRED와 공유) |
