## 0. 이 문서의 위치와 사용법

**시뮬레이션에서 증명할 수 있는 것은 이미 증명했다.** 호스트 단위시험 24종,
새니타이저(ASan/UBSan/TSan) 클린, PX4 SITL 3종(제어 세션 수명주기·SM 결함주입
9/9·유도 추종), Gazebo 3종(접근·회피·풍선 순찰)이 CI와 로컬에서 모두 통과한
상태다. 그러므로 이 체크리스트는 **시뮬로 대체 불가능한 항목만** 담는다 —
드라이버·장치 포맷·실측 지연·열·전원·실제 기체 거동.

각 항목의 형식:

- **판정 기준**: 통과/실패를 가르는 관측 가능한 조건. "동작함" 같은 서술은 쓰지 않는다.
- **실패 시**: 무엇을 고쳐야 하는지, 또는 어느 설계 결정이 틀렸다는 뜻인지.
- 결과는 §10 기록표에 측정치와 함께 남긴다. **측정치 없는 통과 표시는 통과가 아니다.**

**중단 조건(§9)에 하나라도 걸리면 다음 단계로 진행하지 않는다.** 특히 프로펠러
장착은 B5까지 전부 통과한 뒤에만 한다.

### 진행 순서 (역순 진행 금지)

```
B0 플랫폼/OS  →  B1 카메라  →  B2 Hailo 검출  →  B3 RKNN 보조추적
                                     ↓
              B4 녹화  →  B5 FC 링크(프로펠러 제거)  →  B6 안전감시 지상확인
                                     ↓
                       B7 성능·열  →  B8 비행(호버→패턴→추종)
```

근거: 각 단계는 앞 단계의 출력을 입력으로 쓴다. 카메라가 60 fps를 못 주면 B2의
지연 실측이 의미가 없고, 검출이 불안정하면 B3의 연관 품질을 평가할 수 없다.
FC 링크(B5)를 인지 계층(B1~B4)보다 뒤에 두는 이유는 **시커가 FC를 건드리지
않는다는 불변식** 때문이다 — 인지 계층은 FC 없이 단독으로 전부 검증된다.

## 3. B2 — Hailo-8 검출 (SEEKER-SDD §4.4.5 원본)

| # | 항목 | 판정 기준 | 실패 시 |
|---|---|---|---|
| B2-1 | 입력 vstream 포맷 | RGB888 / NHWC / uint8. 다르면 `init()`이 fail-closed로 잡는다 | HEF 재컴파일 또는 전처리 출력 포맷 변경 |
| B2-2 | 출력 format order | `HAILO_NMS_BY_CLASS` 여부, 클래스 수·`max_bboxes` 실값 | raw 헤드 디코드 폴백으로 강등(설계상 열려 있음) |
| B2-3 | threshold API | 보유 HailoRT에서 `set_nms_score_threshold`/`set_nms_iou_threshold` 지원 여부 | 미지원이면 HEF 컴파일 임계를 `SCORE_THR_DEVICE`로 낮춰 동일 효과 |
| B2-4 | RGA 전처리 | RGA 출력 vs CPU 참조 픽셀 비교(허용 오차 내), stride/정렬 제약 확인 | RGA 경로 비활성화(CPU 폴백은 정확성 기준) 후 성능 영향 재평가 |
| B2-5 | **추론 지연 실측** | EMA 지연·발열 기록. 60 Hz 예산(16.6 ms) 대비 여유 확인 | B7 예산 재배분 |
| B2-6 | **job 수명·타임아웃 (P0-05)** | 추론 중 장치 분리/타임아웃/연속 실패를 인위 주입 → 소멸자 bounded drain이 걸리지 않고, 연속 장애 시 `healthy()` 하강이 **SM-7로 전파**되어 OBC가 이탈 | 완료 콜백의 소유권(shared_ptr) 설계가 틀렸다는 뜻 — S-10 재검토 |
| B2-7 | **교차 확인 효과 실측 (R-11)** | 같은 장면에서 단일 채널 확인 vs 2채널 교차 확인의 **오검출률·확인 지연**을 비교해 `DUAL_CONFIRM_RELAX` 확정. 누락률이 증가하지 않는지 함께 확인 | 누락이 늘면 완화폭을 0으로 되돌린다 — 이 기능은 오검출만 줄이는 것이 목적이다 |

**B2-6은 이번 브링업의 최우선 항목이다.** 심층 코드리뷰 P0-05의 조치가
호스트에서 검증 불가로 남은 유일한 안전 경로다.

|---|---|---|

| B6-2 | SM-3 지오펜스 | `geofence_r`(150 m)·`alt_min/max` 원점이 진입 시점에 고정되는지(`capture_home`) |

## 9. 즉시 중단 조건

다음 중 하나라도 관측되면 **비행 단계로 진행하지 않고** 설계로 되돌아간다.

1. **B0-6 실패** — 프로덕션 프로필에서 합성 폴백이 살아 있음(I6 위반).
2. **B2-6 실패** — 검출기 장애가 `healthy()`→SM-7로 전파되지 않음. 유도가
   낡은 대상 정보를 계속 소비하게 된다.
3. **B5-4/B5-5 실패** — 진입·이탈 또는 오버라이드 감지 불능. 조종자가 기체를
   되찾을 수 없다는 뜻이다.
4. **B6-4 실패** — 배터리 게이트 미동작.
5. **시커가 FC에 쓰기를 시도한 흔적** — 계층 불변식 위반. 즉시 중단.
